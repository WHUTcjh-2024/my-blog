# 核心项目

这里集中展示能够说明工程能力的项目。每个项目优先回答四个问题：解决了什么问题、系统如何设计、关键技术如何落地、实验或交付中遇到了什么问题。

## 基于 RAG 的多模态电商智能导购 Agent

面向商品信息分散、用户需求表达不完整和推荐结果难解释的问题，构建商品知识库与检索增强问答流程，并通过 Agent 工具调用组织多轮导购对话。

- **技术栈：** FastAPI、RAG、向量数据库、多模态检索、Agent 工具调用
- **工程重点：** 商品知识库构建、检索增强问答、多轮状态管理、推荐解释
- **项目复盘：** [查看完整说明](/projects/RAG-agent)

## 基于 SIREN 与 PINNs 的激光衍射自动测量系统

围绕激光衍射实验中的条纹中心定位与测量精度问题，将 OpenCV 图像处理、SIREN 隐式表示和 PINNs 物理约束建模组合为自动测量流程。

- **技术栈：** PyTorch、SIREN、PINNs、OpenCV、图像处理
- **工程重点：** 条纹中心定位、物理约束、亚像素级测量、误差分析
- **项目复盘：** [查看完整说明](/projects/SIREN-PINNs)

## Spaceship Titanic Kaggle 实战

完成表格分类任务的端到端实践：字段理解、缺失值处理、特征构造、OneHot 编码、标准化、PyTorch MLP 训练、验证和提交。

- **技术栈：** PyTorch、scikit-learn、pandas、MLP
- **结果：** Kaggle 公开榜得分 **0.79845**
- **项目复盘：** [查看完整说明](/kaggle/Spaceship%20Titanic)
