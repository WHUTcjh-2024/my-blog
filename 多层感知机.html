多层感知机MLP ​

最简单的深度网络是多层感知机，接下来我来阐述我的理解，以展示我的学习成果与思考。

激活函数 ​

首先得掌握一下激活函数，因为我们之前讨论的全都是线性模型，而从现在开始将讨论非线性模型。就激活函数正扮演了这样一个角色——给网络引入非线性。

常见的激活函数youuReLU、Sigmoid、Tanh，我们这里先讨论ReLU。

markdown
ReLU(X) = max(0,x)

直观含义就是把小于0的部分直接去掉，大于0的部分保留。

MLP为什么比线性模型强 ​

层数多= 更强？实则不然，如果没有激活函数，那么Y = W3(W2(W1X)),本质上还是Y = WX ，因为完全可以看成W = W1W2W3 ,它依然是一个线性变换。没有非线性，深度就没有意义。MLP到底在做什么事情，实际上它在不断地做空间变换。所以ChatGPT告诉我一个定理：万能逼近定理。定理是这样描述的：只要神经元足够多，激活函数合理，那么MLP理论上可以拟合任意复杂关系。那为什么后面还有CNN、RNN、Transformer？其实它们本质上都是同样的结构：先行曾+非线性。现实里MLP并不是万能的，也受到一些约束。

python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt
import numpy as np

X = torch.tensor([
    [0.,0.],
    [0.,1.],
    [1.,0.],
    [1.,1.]
])
y = torch.tensor([
    [0.],
    [1.],
    [1.],
    [0.]
])
#线性模型
class LinearModel(nn.Module):
    def __init__(self):
        super().__init__()#必须先调用父类的初始化
        self.net = nn.Sequential(
            nn.Linear(2, 1),
            nn.Sigmoid()
        )
    def forward(self, x):
        return self.net(x)
# MLP
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2,4),
            nn.ReLU(),
            nn.Linear(4,1),
            nn.Sigmoid()
        )
    def forward(self, x):
        return self.net(x)

model = MLP()
# model = LinearModel()

# 损失函数
criterion = nn.BCELoss()
# 优化器
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
# 训练
loss_history = []
for epoch in range(10000):
    pred = model(X)
    loss = criterion(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    loss_history.append(loss.item())

# 输出最终预测
with torch.no_grad():
    pred = model(X)
    print("预测结果：")
    print(pred.round())

从零实现MLP ​

这里我先了解了计算图的概念，计算图就类似于记住来时路，记住每一步是怎么算出来的，比如：

markdown
X -> Linear -> ReLU -> Linear -> loss

PyTorch会记住这些操作，然后当调用loss.backward()的时候，它就会沿着这张图反向求导。

另外，一个十分需要注意的地方是输入展平，因为MLP只认一维向量。所以要对输入进行一些处理。

这里使用Fashion-MNIST 的 MLP来举例，我只手写出核心部分的代码：

python

num_inputs = 784
num_hiddens = 256
num_outputs = 10

w2 = torch.randn(num_hiddens,num_outputs,requires_grad = True)*0.01
b2 = torch.zeros(num_outputs,requires_grad = True)

param = [w1,b1,w2,b2]

#激活函数
def relu(X):
    return torch.clamp(X,min = 0)

欠拟合过拟合 ​

欠拟合：模型太弱，训练集都学不好

过拟合：训练集学的太细了，噪声也学了

说白了就是比较训练损失和验证损失，可以用matplotlib画图来可视化，理想情况下，二者都是下降的。

至于训练轮数过多，这里提出了一个早停思想，这个思想我在之前玩的一个yolo训练中也用到过，说白了就是学不动就别学了，再学下去也改变不了那就停下吧，大概就是这个意思，本质上就是防止过拟合。

正则化 ​

这里说一下比较经典的正则化方法：L2正则化，也叫权重缩减。

正则化的目标其实不是学的多好，而是提高泛化能力，也就是当喂给模型它从来没有见过的数据的时候，它也能表现很好，这是我们希望看到的。

我先阐述一下我对权重缩减的理解：在梯度下降中加入了λw，所以它会把权重往小了压。之所以对权重进行缩减而不是偏置进行缩减，原因就在于，真正决定模型复杂度的通常是权重，所以工程里只对L2做正则化处理。

L2正则化不是提高训练能力，相反，它甚至可能会降低模型在训练集上的表现，但是模型在验证集上的表面会好起来。这反而是我们想要的，这就是泛化。

L1与L2正则化的区别 ​

单纯地想防止过拟合，只需要加L2正则化就行了。它俩的区别是惩罚的方式不同，前者是w,后者是w的平方。这就决定L1正则化是可以选择特征的，而L2正则化不行。

暂退法 ​

这里直接写一个带有Dropout的MLP：

python
import torch
from torch import nn

net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784,256),
    nn. ReLU(),
    nn.Dropout(0.5);#有50%的概率丢弃神经元
    nn.Linear(256,10)
)

暂退法其实也是为了提升模型的泛化能力，因为它强制神经元之间不形成依赖，它会随机关闭神经元，从而减少过拟合。

神经网络的完整闭环 ​

输入数据 -> 前向传播 -> 输出预测 -> 算损失 -> 反向传播 -> 求出梯度 -> 更新参数。

这里我想提一下高等数学中的链式法则，如果我们将其层层展开，即可发现它其实就是在进行逐步求导，而这个过程是从后往前的，所以称为反向传播。反向传播依赖于计算图。

这里李沐的课程中还提到了一点：环境与分布偏移。总结一句话，模型的泛化能力不只是取决于网络结构，训练数据和真实环境是否一致也至关重要。
