线性神经网络之softmax回归 ​

这里展示我的学习理解及成果，如有不正确部分请指出，谢谢。

关于softmax回归 ​

softmax回归常用于线性神经网络中的分类任务，且softmax回归是一个线性模型。它的核心我认为是用线性模型做多分类，再把输出变为概率，用交叉熵训练。这里我没有学习它的底层数学实现，所以可能后面用到的时候再补。

softmax回归的实现 ​

这里李沐老师的d2l一书中讲的有点看不懂，评论区很多人也这么反馈，我借助了其他渠道来学习。

比如Fashion-MNIST数据集中，要判断一个图是T恤、裤子、鞋子还是包包，因为一张图只能属于一个类，所以输出不是一个数，而是所有类别的概率，哪个概率最大，就是哪个。

模型先输出一组原始分数，称为logits，这些分数本身不是概率，softmax的作用就是把它们变成概率且和为1，概率最大的哪个类别就是模型预测结果。

损失函数是交叉熵，二分类里最常用二元交叉熵，多分类任务最常用多分类交叉熵。

从我的角度出发，softmax回归做的事情其实很简单：先算logits，再用softmax把logits变成概率，最后用交叉熵衡量正确类别的概率。

这里ChatGPT给出了一个例子，我觉得比较直观。对于一张输入图像x，因为softmax回归是线性回归，所以模型会输出

markdown
z = xW + b

这里z就是logits，比如有3个类别，就输出：

markdown
x = [2.0,1.0,0.1]

然后softmax把logits变成概率：

$\hat{y}_j = \frac{e^{z_j}}{\sum_k e^{z_k}}$

上面的例子大概会变成：

markdown
[0.66,0.24,0.10]

进而进行交叉熵，也就是惩罚，用-log(p)的原因是惩罚力度足够，所以真数不用1-p。比如正确类别概率是p = 0.01，那么-log(0.01)大致等于4.6，而-log(0.99)大致等于0.99。

另外概率论中提到最大似然估计，交叉熵就是从中推出来的。

取对数的原因：我们想放大正确的概率，缩小失败的概率，当p接近0的时候，log p 会非常小，加个负号会变得特别大，说白了惩罚的够狠。

简洁实现 ​

python
import torch.nn as nn
loss = nn.CrossEntropyLoss(reduction = 'None')

这里有需要注意的细节：CrossEntroyLoss期望输入logits而不是softmax概率，所以不要先写softmax再写CrossEntroyLoss。
