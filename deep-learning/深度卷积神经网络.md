# 深度卷积神经网络 AlexNet

这里简单阐述一下AlexNet的我对个人理解。

AlexNet的典型结构大致是这样的：
```text
输入
→ 卷积层
→ ReLU
→ 池化
→ 卷积层
→ ReLU
→ 池化
→ 卷积层
→ 卷积层
→ 卷积层
→ 池化
→ 全连接层
→ 全连接层
→ 全连接层
→ 输出
```
# AlexNet比传统的CNN强

AlexNet的层数更多，然后它常用的激活函数是ReLU,训练比较块，而且它十分依赖GPU，所以与现代的算力结合的比较深，另外它使用了Dropout和数据增强等技巧来减轻过拟合。

AlexNet是一个把卷积神经网络从“学术可行”推进到“工业可用”的经典深度模型。

它的优点是完整覆盖了CNN的训练全链路，但是它参数量偏大，尤其是后面的全连接层，参数量巨大，是非常吃显存的。

## 工程角度

从工程角度看，AlexNet 的训练过程非常具有参考价值：

ReLU 激活函数：加快训练收敛速度，解决梯度消失问题；

Dropout：在全连接层中随机丢弃神经元，减少过拟合，增强模型泛化能力；

数据增强：随机裁剪、翻转、颜色扰动等，提升模型对现实图像多样性的适应能力；

GPU 并行训练：利用显卡加速卷积运算，使得大规模深度网络的训练成为可能。

AlexNet的核心思想是层次化特征提取：

浅层卷积：提取边缘、线条等低级特征
中层卷积：组合局部特征，形成纹理、角点等中级模式
深层卷积：整合局部模式，形成物体的高层语义特征
全连接层：将提取到的高层特征映射到分类空间，输出类别概率

它有很多卷积层，每一层与每一层之间层层递进，进而完成浅层卷积、中层卷积、深层卷积。
