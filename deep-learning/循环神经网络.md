# 循环神经网络（RNN）

## 概述

循环神经网络（Recurrent Neural Network，RNN）是一类专门用于处理**序列数据**的神经网络架构。与传统的前馈神经网络不同，RNN具有**记忆能力**，能够捕捉序列中的时序依赖关系，广泛应用于自然语言处理、语音识别、时间序列预测等领域。

## 核心思想

### 1. 序列数据的挑战

传统神经网络处理固定长度的输入，但现实中的很多数据是序列形式：
- 自然语言：句子长度不固定
- 语音信号：时变的音频序列
- 时间序列：股票价格、气温变化等

### 2. 循环连接

RNN的核心是**循环连接**，网络在时间步 t 的状态不仅取决于当前输入，还取决于上一时间步的状态：

```
h_t = f(W_h · h_{t-1} + W_x · x_t + b)
```

其中：
- `h_t`：时间步 t 的隐藏状态
- `x_t`：时间步 t 的输入
- `W_h`：隐藏层权重
- `W_x`：输入层权重
- `f`：激活函数（通常为tanh或ReLU）

### 3. 参数共享

RNN在所有时间步上共享相同的参数：
- 减少了参数数量
- 使网络能够处理任意长度的序列
- 提高了泛化能力

## 网络架构

### 基本RNN结构

```
时间步 t-1          时间步 t          时间步 t+1
    │                  │                  │
    x_{t-1}           x_t               x_{t+1}
    │                  │                  │
    ▼                  ▼                  ▼
┌───────┐          ┌───────┐          ┌───────┐
│ tanh  │ ───────► │ tanh  │ ───────► │ tanh  │
└───────┘          └───────┘          └───────┘
    │                  │                  │
    ▼                  ▼                  ▼
  h_{t-1}            h_t              h_{t+1}
    │                  │                  │
    ▼                  ▼                  ▼
  y_{t-1}            y_t              y_{t+1}
```

### 数学表达

对于时间步 t：

1. **隐藏状态更新**：
   ```
   h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b_h)
   ```

2. **输出计算**：
   ```
   y_t = W_hy · h_t + b_y
   ```

3. **整个序列的处理**：
   ```
   h_0 = 0 (初始隐藏状态)
   h_1 = tanh(W_hh · h_0 + W_xh · x_1 + b_h)
   h_2 = tanh(W_hh · h_1 + W_xh · x_2 + b_h)
   ...
   h_T = tanh(W_hh · h_{T-1} + W_xh · x_T + b_h)
   ```

## 代码实现

```python
import torch
import torch.nn as nn

class RNN(nn.Module):
    """基本RNN实现"""
    def __init__(self, input_size, hidden_size, output_size):
        super(RNN, self).__init__()
        self.hidden_size = hidden_size

        # 权重矩阵
        self.W_xh = nn.Linear(input_size, hidden_size)  # 输入到隐藏
        self.W_hh = nn.Linear(hidden_size, hidden_size, bias=False)  # 隐藏到隐藏
        self.W_hy = nn.Linear(hidden_size, output_size)  # 隐藏到输出

    def forward(self, x, h_prev=None):
        """
        Args:
            x: 输入序列 (batch_size, seq_len, input_size)
            h_prev: 初始隐藏状态 (batch_size, hidden_size)
        Returns:
            outputs: 所有时间步的输出 (batch_size, seq_len, output_size)
            h_n: 最后一个时间步的隐藏状态
        """
        batch_size, seq_len, _ = x.size()

        if h_prev is None:
            h_prev = torch.zeros(batch_size, self.hidden_size, device=x.device)

        outputs = []
        h_t = h_prev

        for t in range(seq_len):
            x_t = x[:, t, :]  # 当前时间步的输入
            h_t = torch.tanh(self.W_xh(x_t) + self.W_hh(h_t))  # 更新隐藏状态
            y_t = self.W_hy(h_t)  # 计算输出
            outputs.append(y_t.unsqueeze(1))

        outputs = torch.cat(outputs, dim=1)  # (batch_size, seq_len, output_size)
        return outputs, h_t


class RNNClassifier(nn.Module):
    """用于分类的RNN"""
    def __init__(self, vocab_size, embed_size, hidden_size, num_classes, num_layers=1):
        super(RNNClassifier, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.rnn = nn.RNN(embed_size, hidden_size, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_size, num_classes)

    def forward(self, x):
        # x: (batch_size, seq_len)
        embedded = self.embedding(x)  # (batch_size, seq_len, embed_size)
        output, hidden = self.rnn(embedded)  # output: (batch_size, seq_len, hidden_size)
        # 取最后一个时间步的输出
        last_output = output[:, -1, :]  # (batch_size, hidden_size)
        out = self.fc(last_output)  # (batch_size, num_classes)
        return out


class RNNLM(nn.Module):
    """RNN语言模型"""
    def __init__(self, vocab_size, embed_size, hidden_size, num_layers=1):
        super(RNNLM, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.rnn = nn.RNN(embed_size, hidden_size, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_size, vocab_size)

    def forward(self, x, hidden=None):
        # x: (batch_size, seq_len)
        embedded = self.embedding(x)  # (batch_size, seq_len, embed_size)
        output, hidden = self.rnn(embedded, hidden)  # output: (batch_size, seq_len, hidden_size)
        output = self.fc(output)  # (batch_size, seq_len, vocab_size)
        return output, hidden

    def generate(self, start_token, max_len, temperature=1.0):
        """生成文本"""
        self.eval()
        generated = [start_token]
        input_token = torch.tensor([[start_token]])
        hidden = None

        with torch.no_grad():
            for _ in range(max_len):
                output, hidden = self.rnn(self.embedding(input_token), hidden)
                logits = self.fc(output[:, -1, :]) / temperature
                probs = torch.softmax(logits, dim=-1)
                next_token = torch.multinomial(probs, 1).item()
                generated.append(next_token)
                input_token = torch.tensor([[next_token]])

        return generated
```

## 训练过程

### 1. 前向传播
- 按时间步顺序处理输入序列
- 每个时间步计算隐藏状态和输出
- 保存所有中间状态用于反向传播

### 2. 反向传播（BPTT）
**时间反向传播（Backpropagation Through Time）**是RNN的训练算法：

- 从最后一个时间步开始反向传播
- 梯度通过时间步逐层传播
- 所有时间步共享参数，梯度需要累加

### 3. 梯度问题

**梯度消失（Vanishing Gradient）：**
- 梯度在反向传播过程中指数级衰减
- 难以学习长距离依赖关系
- 是RNN的主要限制

**梯度爆炸（Exploding Gradient）：**
- 梯度在反向传播过程中指数级增长
- 导致训练不稳定
- 可以通过梯度裁剪解决

### 2. LSTM单元结构

LSTM引入了**细胞状态（Cell State）**和三个**门控机制**：

```
        ┌─────────────────────────────────────┐
        │            Cell State               │
        │    C_{t-1} ──────────────────► C_t  │
        │        │    ┌───────┐    │          │
        │        ├────│ Forget│────┤          │
        │        │    │ Gate  │    │          │
        │        │    └───────┘    │          │
        │        │    ┌───────┐    │          │
        │        ├────│ Input │────┤          │
        │        │    │ Gate  │    │          │
        │        │    └───────┘    │          │
        │        │    ┌───────┐    │          │
        │        └────│Output │────┘          │
        │             │ Gate  │               │
        │             └───────┘               │
        └─────────────────────────────────────┘
```

**三个门控：**

1. **遗忘门（Forget Gate）**：
   ```
   f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
   ```
   决定从细胞状态中丢弃哪些信息

2. **输入门（Input Gate）**：
   ```
   i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
   C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)
   ```
   决定哪些新信息存入细胞状态

3. **输出门（Output Gate）**：
   ```
   o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
   ```
   决定从细胞状态中输出哪些信息

**状态更新：**
```
C_t = f_t * C_{t-1} + i_t * C̃_t
h_t = o_t * tanh(C_t)
```

### 3. LSTM代码实现

```python
class LSTM(nn.Module):
    """LSTM实现"""
    def __init__(self, input_size, hidden_size, num_layers=1, dropout=0):
        super(LSTM, self).__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers

        # 使用PyTorch内置LSTM
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            dropout=dropout if num_layers > 1 else 0,
            batch_first=True
        )

    def forward(self, x, hidden=None):
        """
        Args:
            x: (batch_size, seq_len, input_size)
            hidden: (h_0, c_0) 初始隐藏状态和细胞状态
        Returns:
            output: (batch_size, seq_len, hidden_size)
            hidden: (h_n, c_n) 最后的隐藏状态和细胞状态
        """
        output, hidden = self.lstm(x, hidden)
        return output, hidden
```

## 门控循环单元（GRU）

### 1. GRU的特点

GRU是LSTM的简化版本，由Cho等人在2014年提出：
- 将遗忘门和输入门合并为**更新门**
- 将细胞状态和隐藏状态合并
- 参数更少，计算更快

### 2. GRU单元结构

```
h_{t-1} ─────────────────────────────► h_t
    │        ┌───────┐                  ▲
    ├────────│ Reset │                  │
    │        │ Gate  │                  │
    │        └───────┘                  │
    │        ┌───────┐                  │
    └────────│Update │──────────────────┘
             │ Gate  │
             └───────┘
```

**两个门控：**

1. **重置门（Reset Gate）**：
   ```
   r_t = σ(W_r · [h_{t-1}, x_t])
   ```

2. **更新门（Update Gate）**：
   ```
   z_t = σ(W_z · [h_{t-1}, x_t])
   ```

**状态更新：**
```
h̃_t = tanh(W · [r_t * h_{t-1}, x_t])
h_t = (1 - z_t) * h_{t-1} + z_t * h̃_t
```

### 3. GRU代码实现

```python
class GRU(nn.Module):
    """GRU实现"""
    def __init__(self, input_size, hidden_size, num_layers=1, dropout=0):
        super(GRU, self).__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers

        self.gru = nn.GRU(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            dropout=dropout if num_layers > 1 else 0,
            batch_first=True
        )

    def forward(self, x, hidden=None):
        output, hidden = self.gru(x, hidden)
        return output, hidden
```

## RNN的应用

### 1. 自然语言处理

**语言模型：**
- 预测下一个词的概率
- 文本生成
- 机器翻译

**文本分类：**
- 情感分析
- 垃圾邮件检测
- 主题分类

**命名实体识别：**
- 识别人名、地名、机构名
- 序列标注任务

### 2. 语音识别

- 语音转文字
- 说话人识别
- 语音情感分析

### 3. 时间序列预测

- 股票价格预测
- 天气预报
- 异常检测

### 4. 音乐生成

- 自动生成音乐序列
- 风格迁移
- 旋律生成

## RNN的局限性

### 1. 长距离依赖问题
- 基本RNN难以学习长距离依赖
- LSTM和GRU有所改善，但仍有限制
- Transformer架构更好地解决了这个问题

### 2. 训练效率
- 无法并行计算（必须按时间步顺序处理）
- 训练速度慢
- 难以利用GPU并行能力

### 3. 梯度问题
- 梯度消失/爆炸
- 需要特殊的初始化和正则化技巧

## 总结

RNN及其变体（LSTM、GRU）是处理序列数据的重要工具：

- **记忆能力**：能够捕捉时序依赖关系
- **灵活架构**：支持多种输入输出模式
- **广泛应用**：NLP、语音、时间序列等领域
- **持续发展**：从RNN到LSTM、GRU，再到Transformer

虽然Transformer在很多任务上取代了RNN，但RNN的思想和架构仍然是深度学习的重要基础，理解RNN对于掌握现代序列模型至关重要。
